# VrnxStudy

VrnxStudy is a full-stack exam preparation and test platform.

## Tech Stack

- Frontend: Angular
- Backend: Spring Boot
- Database: PostgreSQL
- Version Control: Git and GitHub
- Deployment: Docker (planned)

## Core Features

- Exam, subject and chapter management
- Question bank and test creation
- Practice tests and timed exams
- Attempt history and result analytics
- Admin dashboard

## Project Status

Planning and foundation setup.

## Repository Structure

- `frontend/` — Angular application
- `backend/` — Spring Boot API
- `docs/` — Project documentation
- `infrastructure/` — Deployment configuration
